# T-007 i18n: Dict*.kt → JSON converter and I18nCore port

**Status:** ready-for-agent  
**Issue:** #7  
**Milestone:** M0 Scaffold

## What to build

Write `scripts/dict-to-json` that reads the Android `Dict*.kt` files (9-column blocks plus the two-column Nl/Ar/Pl/EnLang files) and writes one JSON per language with the German text as key. Port `I18nCore` rules: 12 languages, hr/sr fall back to bs, other empties to en, placeholders `{0}` and `{#0}`. Arabic switches the layout to RTL.

## Acceptance criteria

- [ ] Script output is committed under `src/i18n/` and is reproducible from Android `f4a0360`.
- [ ] Ported tests pass.
- [ ] Switching to Arabic mirrors the layout (sidebar side, text alignment).
- [ ] A missing key logs once and shows the German text, as on Android.
